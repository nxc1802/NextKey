\subsection{Communication Plan}
To ensure methodological alignment, rapid issue resolution, and steady milestone progression, the team adheres to a multi-tiered communication framework:
\begin{itemize}
    \item \textbf{Daily Standups (Asynchronous / 15 Minutes):} Conducted via dedicated Slack/Discord channels to track daily commitments, synchronize code changes, and identify technical blockers early.
    \item \textbf{Weekly Advisor Consultation (1 Hour):} Formal weekly meetings with the Academic Supervisor to review experimental logs, evaluate empirical trade-offs, refine theoretical formulations, and validate subsequent sprint objectives.
    \item \textbf{Version Control and Collaborative Engineering:} Centralized GitHub repository with branch protection rules. All code additions require structured pull requests, passing automated test suites, and peer review prior to integration.
    \item \textbf{Shared Research Registry:} Systematized tracking of model configurations, random seeds, training checkpoints, evaluation logs, and hyperparameter matrices across all experimental phases.
\end{itemize}

\subsection{Quality Management Plan}
To ensure academic rigor, empirical reproducibility, and software reliability:
\begin{itemize}
    \item \textbf{Strict Reproducibility Protocols:} All dataset generation splits, random shuffles, weight initializations, and training runs are seeded deterministically with seed \texttt{42}.
    \item \textbf{Automated Testing Suite:} Continuous testing via \texttt{pytest} verifying data transformation schemas, tensor dimensionality alignment, loss backward flows, and inference pipelines.
    \item \textbf{Standardized 3-Tier Metric Harness:} Candidate models are universally evaluated across Character-level (\ac{CER}, \ac{BF1}), Word-level (\ac{WER}, \ac{WAcc}), and Sentence-level (\ac{EM}, Near-Perfect $\le 5\%$, \ac{BLEU}-4, \ac{ROUGE}-L) metrics.
    \item \textbf{Zero Test Contamination:} The 159,172 external \textit{the\_thao (Sports)} sentences remain completely isolated from training and hyperparameter tuning to ensure uncompromised out-of-distribution evaluation.
\end{itemize}

\subsection{Budget and Resource Allocation}
The NextKey project operates under an open-source, resource-efficient model with zero capital expenditure:
\begin{itemize}
    \item \textbf{Computational Infrastructure:} Cloud-hosted dual Tesla T4 GPUs (via Kaggle and Google Colab academic allocations) combined with local Apple Silicon workstations for rapid prototyping.
    \item \textbf{Software Stack:} Fully open-source ecosystem including PyTorch, Hugging Face Transformers, FastAPI, Streamlit, and Git.
    \item \textbf{Total Direct Financial Budget:} \$0.00 USD.
\end{itemize}

\subsection{Change Management Process}
To accommodate necessary technical adaptations without derailing the overall project schedule:
\begin{enumerate}
    \item \textbf{Gate 1 (Smoke Run Gate):} Any candidate neural architecture that fails to demonstrate training loss convergence within 1,000 steps or exhibits unacceptable latency is discarded early.
    \item \textbf{Gate 2 (Objective Benchmark Gate):} Final architectural decisions must be strictly justified by quantitative metric improvements on shared validation splits rather than subjective preference.
    \item \textbf{Kill Criteria for Extensions:} Secondary research extensions (e.g., dynamic online personalization) are postponed immediately if the primary multi-task restoration pipeline requires further stabilization.
\end{enumerate}

\subsection{Project Closure and Deliverables}
Upon reaching the final project milestone:
\begin{itemize}
    \item \textbf{Artifact and Checkpoint Handover:} All quantized checkpoints, configuration manifests, vocabulary mappings, and evaluation JSON reports are archived with cryptographic SHA-256 checksums.
    \item \textbf{Academic Documentation:} Complete, reproducible source code repositories, benchmark logs, and technical defense slides prepared for capstone examination.
\end{itemize}
