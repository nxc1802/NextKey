\subsection{Project Overview}
In the modern digital communication era, virtual keyboards act as the central interface connecting human thought with computer systems. For the Vietnamese language, traditional input methods like Telex and VNI require users to explicitly encode tone marks and diacritics. This project proposes an intelligent Vietnamese Input Method Editor (IME) that allows users to type a continuous sequence of Latin characters without accents or spaces (similar to the Pinyin input method for Chinese). Utilizing an end-to-end sequence-to-sequence architecture based on Deep Learning, the system automatically predicts the intended Vietnamese sentence with proper word boundaries and diacritics. The model is optimized for low-latency inference and designed to run entirely offline, preserving user privacy while providing a seamless typing experience.

\section{Project Background}

\subsection{Overview of the Field}
Vietnamese is an isolating language with a complex syllable structure consisting of an onset, rhyme, and one of six tone marks. The omission of diacritics and spaces introduces pervasive lexical ambiguity. The current Vietnamese typing methods require users to memorize explicit mapping rules (e.g., using 's', 'f', 'r', 'x', 'j' for tones in Telex) or switch to number rows (in VNI). While accurate, these methods impose a significant cognitive load and physical keystroke overhead.

\subsection{Existing Systems}
Existing systems range from traditional rule-based IMEs to advanced statistical models:
\begin{enumerate}
    \item \textbf{Traditional IMEs (Telex, VNI):} Rely on deterministic keystroke composition. They lack contextual awareness and require high keystroke counts.
    \item \textbf{Statistical and N-gram Models:} Earlier attempts at diacritic restoration used Hidden Markov Models (HMM) and Phrase-based Statistical Machine Translation (SMT). These suffer from the "curse of dimensionality" and fail on unsegmented continuous text.
    \item \textbf{Recurrent Neural Networks (RNN, LSTM, GRU):} While Bi-LSTM and Bi-GRU models achieved good accuracy, their sequential processing nature introduces high inference latency, making them unsuitable for real-time keyboard applications.
    \item \textbf{Modern Transformer Models (BARTpho, T5):} Pretrained Large Language Models have achieved state-of-the-art results in NLP tasks. However, their massive size makes offline mobile deployment challenging without significant optimization.
\end{enumerate}

\subsection{Limitations of Existing Solutions}
\begin{itemize}
    \item \textbf{High Cognitive Load and Physical Strain:} Traditional methods require excessive keystrokes (e.g., typing "tôi" requires 4 keys "tooi" in Telex) and explicit rule memorization.
    \item \textbf{Fragmented Processing:} Many existing AI solutions separate word segmentation and diacritic restoration, causing compounding errors.
    \item \textbf{Latency and Privacy Issues:} Cloud-based predictive models introduce network latency and pose severe privacy risks by transmitting user keystrokes to remote servers.
\end{itemize}

\section{Problem Statement}
Given a continuous sequence of unaccented Latin characters without whitespace (e.g., "toidihoc"), the system must jointly perform word segmentation and diacritic restoration to output the correct Vietnamese sentence (e.g., "tôi đi học" or "tối đi học"). This involves resolving massive homograph ambiguity and ambiguous word boundaries relying purely on global contextual dependency, while maintaining a strict inference latency (e.g., $<50\text{ ms}$) suitable for real-time edge devices without internet connectivity.

\section{Project Objectives}
\begin{itemize}
    \item \textbf{Dataset Construction:} Build a large-scale Vietnamese parallel corpus by converting standard text into unaccented, unsegmented sequences, including synthetic noise modeling for typo simulation.
    \item \textbf{Model Development:} Fine-tune a sequence-to-sequence Deep Learning model (based on the T5/ByT5 architecture) to jointly learn word boundaries and diacritics.
    \item \textbf{Inference Optimization:} Optimize the model for edge devices using techniques like Knowledge Distillation and Quantization to achieve low-latency offline execution.
    \item \textbf{Deployment:} Deploy the trained model as a fully offline backend service integrated with a custom interactive keyboard interface.
\end{itemize}

\section{Significance of the Project}
\begin{itemize}
    \item \textbf{Enhanced Accessibility:} Removes the steep learning curve of Vietnamese typing for foreigners, children, and the elderly by acting as a natural language scaffold.
    \item \textbf{Improved Ergonomics:} Maximizes Keystroke Savings (estimated 20-40\% reduction), significantly increasing typing speed and reducing the risk of Repetitive Strain Injury (RSI).
    \item \textbf{Absolute Privacy:} By executing entirely offline on the edge device, the system guarantees that sensitive user keystroke data is never exfiltrated to the cloud.
\end{itemize}

\section{Project Scope \& Limitations}
\begin{itemize}
    \item \textbf{In-Scope:} Developing the AI model, synthetic data pipeline, model optimization for edge inference, and a backend API demonstrating the continuous typing capabilities.
    \item \textbf{Out-of-Scope:} OS-level low-level driver development for iOS/Android native integration, voice recognition, and handling of highly specialized ancient Vietnamese scripts.
\end{itemize}
