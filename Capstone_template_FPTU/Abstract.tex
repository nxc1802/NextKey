
\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This capstone project, NextKey, addresses the cognitive and physical challenges of typing Vietnamese on mobile devices caused by traditional rule-based methods like Telex and VNI. We propose an intelligent, end-to-end sequence-to-sequence Deep Learning system that allows users to type continuous, unaccented, and unsegmented Latin characters (similar to Pinyin). The model jointly performs word segmentation and diacritic restoration to predict the fully formatted Vietnamese sentence in real time. To ensure seamless interaction and absolute data privacy, the architecture is heavily optimized using Knowledge Distillation and Quantization for offline, low-latency execution on edge devices. This novel input method aims to significantly improve typing ergonomics, maximize keystroke savings, and provide an accessible language scaffold for all users.

\vspace{0.5cm}
\textbf{Keywords:} Vietnamese Input Method, Diacritic Restoration, Word Segmentation, Sequence-to-Sequence Modeling, Edge Computing, Offline Inference.
